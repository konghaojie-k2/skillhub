# Skill Anything

从任意输入内容中提取并生成可复用的 agent skill。

## 核心功能

1. **内容分析** - 理解输入内容的结构、语义和核心能力
2. **Skill 提取** - 从内容中提取可复用的指令和工作流
3. **Skill 生成** - 生成符合 SKILL.md 格式的完整 skill 文件

## 支持的输入类型

| 类型 | 示例 | 提取的 Skill |
|------|------|--------------|
| PDF/论文 | 学术论文、技术文档 | 文档理解、问答、摘要 |
| URL/网页 | 博客、文档站点 | 网页内容提取、结构化 |
| API 文档 | OpenAPI/Swagger | API 调用、代码生成 |
| Git 仓库 | 代码库 | 使用指南、API 参考 |
| 代码文件 | Python/JS/Go | 代码理解、重构建议 |
| 聊天记录 | Slack/Discord 导出 | 知识提取、摘要 |
| 数据库 Schema | SQL 文件 | ER 图、查询优化 |
| 图片/设计稿 | Figma 导出 | 设计规范、组件结构 |
| 配置文件 | Docker/K8s/Terraform | 配置审查、最佳实践 |

## 工作流程

### 1. 分析输入内容

根据输入类型采用不同的分析方法：

- **文件输入**：读取文件内容，识别格式和结构
- **URL 输入**：抓取网页，提取关键信息
- **Git 仓库**：克隆或拉取，分析 README、API、代码结构
- **文本输入**：直接分析文本内容

### 2. 识别核心能力

从内容中提取以下要素：

1. **功能/能力** - 这个内容提供什么功能？
2. **使用场景** - 什么情况下会用到？
3. **输入/输出** - 期望的输入是什么？输出是什么？
4. **约束/限制** - 有什么限制条件？

### 3. 生成 Skill

根据分析结果生成 SKILL.md 格式的输出：

```yaml
---
name: [skill-name]
description: |
  [详细描述 skill 的功能和触发场景]
---

# Skill 名称

## 概述
[1-2 句话说明这个 skill 做什么]

## 使用场景
- 场景 1
- 场景 2

## 工作流程
[如果有复杂的流程，描述步骤]

## 示例
[可选的示例]
```

## 使用示例

### 示例 1：从 PDF 生成 Skill

用户输入：一篇关于 LangChain 的论文
→ 生成一个 "LangChain 论文阅读理解" skill

### 示例 2：从 API 文档生成 Skill

用户输入：一个 OpenAPI spec 文件
→ 生成一个 "调用此 API" skill，包含端点、参数、示例

### 示例 3：从 Git 仓库生成 Skill

用户输入：一个 Python 库的 GitHub 仓库
→ 生成一个 "使用这个库" skill，包含安装、使用示例、API 参考

### 示例 4：从网页生成 Skill

用户输入：一个技术博客文章 URL
→ 生成一个 "阅读理解此博客" skill

## 输出位置

生成的 skill 保存在当前目录下，目录名为输入内容的简化名称。

例如：
- 输入：`https://api.example.com/docs` → 输出：`skill-anything/api-example/`
- 输入：`/path/to/document.pdf` → 输出：`skill-anything/document/`

## 注意事项

- 输入是中文内容时，生成的 skill 描述使用中文
- 输入是英文内容时，使用英文
- 优先提取最有用、最可复用的能力
- 如果内容太大，聚焦于核心功能而非全部细节
