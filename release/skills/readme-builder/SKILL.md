## 注意事项

1. **项目定位要清晰** —— 一句话说清楚解决什么问题
2. **技术栈要准确** —— 列出实际使用的技术
3. **代码示例要可用** —— 给出能直接运行的命令
4. **开发路线要真实** —— 反映实际开发计划
5. **参考优秀案例** —— 如 ClawTeam、流行开源项目
