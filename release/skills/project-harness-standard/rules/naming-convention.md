# 文件命名通用规范模板

> 本文件为模板，每个项目应在 `CONTRIBUTING.md` 中基于本模板定义具体规则。

## 推荐格式

```
{描述}_{YYYYMMDD}_{状态?}.{ext}
```

## 组成说明

| 部分 | 必填 | 格式 | 示例 |
|------|------|------|------|
| 描述 | 是 | 简短中文或英文，不含空格 | `Demura基础业务知识` |
| 日期 | 是 | 8 位数字 `YYYYMMDD` | `20260421` |
| 状态 | 否 | 当前生效 / 已归档 / 草稿 | `当前生效` |
| 扩展名 | 是 | 小写 | `.md` `.png` `.xlsx` |

## 完整示例

| 文件名 | 说明 |
|--------|------|
| `Demura基础业务知识_20260421_当前生效.md` | Markdown 文档，带状态 |
| `before_demura_20260421.png` | 图片，无状态 |
| `项目计划表_20260417.xlsx` | Excel 表格 |
| `技术方案_20260327_客户汇报版.pptx` | PPT，带状态描述 |

## 正则表达式（通用模板）

```regex
.*_\d{8}(_[^/\\]*)?\.[a-zA-Z0-9]+$
```

项目可在此基础上自定义：
- 限制允许的扩展名列表
- 要求或禁止状态后缀
- 限制描述部分的最大长度

## 例外情况

以下文件可豁免日期命名：
- `README.md`（目录说明文件）
- `INDEX.md`（索引文件）
- `.gitignore`
- 配置文件（如 `.claude/settings.json`）
