# 业务背景事实子集（魏桥铝电解）

> 范围：与 `factory-profile` skill 直接相关的事实。其他铝厂或其他工艺需要按本目录结构重新抽取。

## 1. 三厂基本信息

| 厂 | 电流等级 | 槽数 | 时间范围 | 备注 |
|----|----------|------|----------|------|
| lv1p3 | 600kA | 254 | 2025-09-01 ~ 2025-12-31 | 大型化、磁场强、热惯性大 |
| lv3p2 | 400kA | 224 | 2025-09-01 ~ 2026-03-15 | 标准型、热惯性较大 |

## 2. 11 状态变量 - 业务分类

### 控制输入（人工设定值杠杆）
- 基准下料间隔（秒） - 调节氧化铝浓度，**最快响应**（小时级）
- 实际氟盐加料量（kg/日） - 调节分子比，**中速积分效应**（数日级）
- 计划出铝（kg/日） - 辅助调温，**慢速**（周级）
- 工作电压（mV） - 调热平衡，**偏快**（小时级）

> 注：实际采集字段为 `工作电压` 而非 `设定电压`。工作电压 = 槽控机响应后的实际值，跨厂比较应优先用 `工作电压偏差值`（=工作电压 - 参考基准）。

### 状态输出（响应侧）
- 温度（°C） - 管控 945–965
- 分子比 - 600kA 管控 2.15–2.35，400/500kA 管控 2.20–2.40
- 电压残差（mV） - 与过热度反向关联
- 针振（mV） - 槽况不稳定敏感标志（非一一对应）
- 效应电压（mV） - 阳极效应发生信号
- 浓度（斜率） - 数值越大 → 氧化铝浓度越低
- 吸出铝量（kg/日） - 阶跃变化，非出铝日接近 0

### 时窗分类
- **短时窗（小时级）**：工作电压、电压残差、针振、效应电压、浓度（斜率）
- **中时窗（数日级）**：实际氟盐加料量、分子比（3/4 天取样一次）
- **长时窗（周级）**：温度、铝水平（未提供）、吸出铝量

## 3. 缺失率业务解释

- **分子比 67–76% 空值**：业务规则决定，**结构性缺失**。
  - lv1p3 每 4 天取样一次
  - lv3p2、lv5p3 每 3 天取样一次
  - 非测量日为空，**不得简单插值或删除**。
- **lv5p3 浓度（斜率）43.5% 空值**：系统性高缺失，可能与浓度估算策略或数据回传有关，跨厂使用浓度变量时需对 lv5p3 单独处理。
- **lv5p3 效应电压非零 35.6%**：远高于 lv1p3/lv3p2 的 ~5%，存在数据定义不一致或效应频发两种可能，**需先确认数据一致性**。
- 温度、针振、效应电压：基本无空值。

## 4. 延迟时间尺度

| 调控手段 | 作用对象 | 响应速度 |
|----------|---------|----------|
| 设定电压调整 | 工作电压 → 热收入 → 过热度 | 偏快（小时级） |
| 氟盐加料 | 分子比 → 初晶温度 → 槽温 | 中速（数日级） |
| 出铝量调整 | 铝水平 → 散热 → 槽温 | 偏慢（周级） |
| 下料间隔/下料量 | 氧化铝浓度 → 效应发生 | 偏快（小时级） |

**与 08 窗口参数对应**：默认 pre/post 3d 窗口对设定电压、下料间隔动作基本合理；对氟盐、出铝偏短（应看 5–7d）。

## 5. 关键耦合关系（用于解读画像差异）

- **槽温 = 初晶温度 + 过热度**：分子比每降低 0.1，初晶温度约降 3–4°C
- **氟盐加得多 → 分子比走低（非瞬时）**：与时间滞后和累积相关
- **出铝量双向辅助调温**：槽温高 → 调小出铝 → 散热大；槽温低 → 调大出铝 → 散热小
- **电压残差与过热度反向关联**：过热度大 → 压差偏小；过热度小 → 压差偏大
- **针振干扰闭环**：针振大 → 槽控机误判浓度 → 加料失衡 → 沉淀加剧 → 针振进一步增大
- **下料量与基准下料间隔非严格反比**：受过量/欠量加料补偿调节

## 6. 跨厂对比注意

- **物料量绝对值与电流等级成正比**：下料量、吸出铝量不能跨等级直接比较绝对量；用 z-score 后再比较，或用 工艺方视角（每(槽,周)次数）替代。
- **跨厂效应电压可信度不同**：lv1p3/lv3p2 ≈ 5% 非零是稀有事件；lv5p3 = 35.6% 非零，定义可能不同。
- **设备号重叠**：lv1p3 与 lv5p3 设备号范围重叠，跨厂聚合前必须先加 series 标识。
