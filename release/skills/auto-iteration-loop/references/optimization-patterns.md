# 优化方向参考模板

Agent根据当前项目瓶颈动态分析生成优化候选时，可参考以下常见模式：

## 时序切分优化模式

### 参数优化类

| 方向 | 适用场景 | 实施要点 |
|------|----------|----------|
| **贝叶斯优化参数搜索** | 网格搜索效率低 | 用 skopt.gp_minimize 替代网格遍历 |
| **自适应惩罚系数** | PELT惩罚值难以确定 | 根据数据长度动态调整 |
| **动态min_size** | 固定最小段长不适用 | 按数据方差自适应设置 |

### 特征增强类

| 方向 | 适用场景 | 实施要点 |
|------|----------|----------|
| **多尺度特征提取** | 单尺度遗漏细节 | 同时计算多窗口统计量 |
| **滚动统计特征** | 突变检测不足 | 添加滚动均值差、滚动方差比 |
| **趋势变化特征** | 渐变工况识别 | 计算局部斜率变化率 |
| **TCN/LSTM编码** | 复杂模式难以捕捉 | 深度学习提取潜在特征 |

### 算法改进类

| 方向 | 适用场景 | 实施要点 |
|------|----------|----------|
| **分层切分策略** | 全局切分精度不足 | 先粗切分再分段细切 |
| **多模型加权投票** | 单模型不稳定 | 不同算法加权组合 |
| **后处理边界优化** | 切分点位置偏差 | 在切分点附近微调 |

### 评估改进类

| 方向 | 适用场景 | 实施要点 |
|------|----------|----------|
| **自适应评估权重** | 四指标等权不合理 | 根据数据特性动态调整 |
| **新增评估指标** | 现有指标不全面 | 如：工况持续时长合理性 |
| **约束惩罚增强** | 违反约束时有发生 | 添加硬约束惩罚项 |

## 瓶颈诊断映射

根据评估结果诊断瓶颈，选择对应优化方向：

```
瓶颈诊断规则:

IF intra_variance 偏高:
  → 考虑: 多尺度特征、滚动统计特征、增加n_bkps

IF inter_distance 偏低:
  → 考虑: 特征增强、调整min_size、分层切分

IF step_alignment 偏低:
  → 考虑: TCN编码、趋势变化特征、后处理边界优化

IF transition_smoothness 偏低:
  → 考虑: 减少n_bkps、增加min_size、边界微调

IF overall 停滞:
  → 考虑: 贝叶斯优化、自适应权重、多模型加权
```

## 实施风险评估

| 风险等级 | 判断标准 | 示例 |
|---------|----------|------|
| **低风险** | 改动小、易回滚 | 参数优化、权重调整 |
| **中风险** | 新增模块、需测试 | 新特征计算、新算法集成 |
| **高风险** | 重构核心、影响大 | 深度学习改造、架构变更 |

优先选择低风险、高预期收益的方向。
