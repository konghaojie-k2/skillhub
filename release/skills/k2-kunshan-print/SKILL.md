# k2-kunshan-print Skill

## 功能描述

昆山出差报销自动化处理技能。**供 AI 助手使用**，自动完成以下流程：

1. **检查必要文件** - 验证发票、出差申请等必备材料是否齐全
2. **读取发票信息** - 从 PDF 发票中提取日期、金额、类型等信息
3. **读取滴滴行程明细** - 从滴滴行程单中提取每笔行程的日期和金额，按日期汇总
4. **识别公司选择** - 从用户自然语言中自动识别公司
5. **填写报销单** - 在原始报销单模板基础上填写数据
6. **设置打印机** - 配置 HP 物理打印机为默认打印机
7. **优化打印顺序** - 按发票时间顺序排序，最后打印报销单 Excel
8. **批量打印** - 发送所有文件到打印机

## 费用填写规则

### 重要：模板清理

**填写前必须清空模板中原有的所有数据！**

需要清空的单元格：
- 第 17 行：日期行（D-J 列）
- 第 18-19 行：出发/到达地点（D-J 列）
- 第 20-27 行：所有费用行（D-J 列）
- 第 28 行：每列合计（D-J 列，保留 K 列公式）

### 出差目的详述

填写在 **B10 单元格**

### 住宿费（公司规定）
**住宿费必须填写在出差的最后一天**

### 其他费用
- **火车票/机票**：按实际出行日期填写
- **打车费**：从滴滴行程单读取明细，按日期汇总填写
- **出差补助**：按天数填写（开始日期、中间日期、结束日期都填）

### 填写示例

**出差期间：3 月 9 日 - 3 月 11 日（2.5 天）**

```
| 项目       | 3 月 9 日 | 3 月 10 日 | 3 月 11 日 |
|------------|----------|-----------|-----------|
| 出发地点   | 苏州     | (空)      | 合肥      |
| 到达地点   | 合肥     | (空)      | 苏州      |
| 火车票     | 170.00   | (空)      | 185.00    |
| 打车费     | 39.20    | (空)      | 38.60     |
| 住宿费     | (空)     | (空)      | 457.30    |
| 出差补助   | 90.00    | 180.00    | 180.00    |
```

**说明：**
- 日期行：3 天都填
- 出发/到达地点：只填 2 列（有行程的日期）
- 火车票：只填 2 张（9 日和 11 日）
- 打车费：只填 2 列（9 日和 11 日，按滴滴行程明细汇总）
- 住宿费：只填 1 个（最后一天）
- 出差补助：3 天都填（90 + 180 + 180 = 450 元）

### 补贴标准
- 半天补贴：90 元（出发/返程时间晚于 12:00）
- 全天补贴：180 元

## 处理流程

```
1. 检查必要文件
   └─ 验证 PDF 发票是否存在
   └─ 验证报销单模板是否存在

2. 读取发票信息
   └─ 识别发票类型（火车/打车/住宿）
   └─ 提取发票日期
   └─ 提取发票金额

3. 读取滴滴行程明细
   └─ 从行程单中提取每笔行程
   └─ 按日期汇总金额

4. 识别公司选择
   └─ 从用户自然语言中提取关键词
   └─ 自动选择对应公司

5. 计算出差补助
   └─ 从火车票推断出差日期范围
   └─ 计算天数
   └─ 计算补助金额

6. 填写报销单
   └─ 清空模板原有数据
   └─ 填写公司名称
   └─ 填写基本信息（出差目的在 B10）
   └─ 填写日期（3 天）
   └─ 填写出发/到达地点（2 列）
   └─ 填写火车票（2 张）
   └─ 填写打车费（按日期汇总）
   └─ 填写住宿费（最后一天）
   └─ 填写出差补助（3 天）
   └─ 保存 Excel 文件

7. 设置打印机
   └─ 设置 HP 物理打印机为默认
   └─ 避开虚拟 PDF 打印机

8. 优化打印顺序
   └─ 按发票时间排序
   └─ 交通费 → 住宿费 → 其他 → 报销单

9. 批量打印
   └─ 发送所有文件到打印机
   └─ 确认打印队列
```

## 注意事项

1. **填写前必须清空模板** - 用户需手动清理模板中原有的数据
2. **出差目的填写在 B10** - 不是 B8 或其他位置
3. **住宿费填写在最后一天** - 公司规定
4. **打车费按日期汇总** - 从滴滴行程单读取明细，按日期加和
5. **出差补助 3 天都填** - 开始日期、中间日期、结束日期
6. **打印前确认打印机** - 确保 HP 打印机已开机并有纸张
7. **如 WPS 弹出 PDF 导出窗口** - 点击"取消"按钮
8. **自然语言识别** - 支持从用户描述中自动识别公司
