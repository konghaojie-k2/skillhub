# k2-kunshan-print 技能使用说明

## 功能概述

昆山出差报销自动化处理技能 v2.0，自动完成：
1. ✅ 检查必要文件（发票、出差申请）
2. ✅ 读取发票信息（日期、金额、类型）
3. ✅ OCR 识别出差申请截图
4. ✅ 按实际发票日期构建报销单日期列
5. ✅ 智能计算补贴（按首末程交通工具时间，12:00 分界）
6. ✅ 区分火车票退票与正常车票
7. ✅ 填写报销单并自动校验
8. ✅ 设置 HP 物理打印机为默认
9. ✅ 按规则顺序批量打印所有材料

## 打印对象逻辑

- **住宿费**：发票 + 结账单（两者都打印）
- **打车费**：电子发票 + 行程报销单（两者都打印）
- **火车票/机票**：只要发票
- **报销单 Excel**：最后打印

skill 会自动识别文件夹中所有 PDF 文件，已识别的发票按时间排序先打，未被识别为发票的附件（如滴滴电子发票、住宿电子发票）也会一并打印，确保不遗漏任何报销材料。

## 费用填写规则

### 重要：模板清理

填写前会自动清空模板中原有的所有数据！

### 日期列构建规则

**以实际发票/车票日期为准**，而非出差申请日期。系统会收集所有火车票、打车行程单的实际日期，生成报销单的日期列。

### 住宿费（公司规定）

**住宿费必须填写在出差的最后一天**

示例：
```
出差期间：3 月 9 日 - 3 月 11 日（3 天）

报销单填写：
| 费用类型 | 3 月 9 日 | 3 月 10 日 | 3 月 11 日 |
|----------|----------|-----------|-----------|
| 火车票   | 170.00   | -         | 185.00    |
| 打车费   | 53.50    | 24.30     | -         |
| 住宿费   | -        | -         | 457.30    | ← 填写在最后一天
| 出差补助 | 90.00    | 180.00    | 180.00    |
```

### 补贴计算规则

- **首程出发时间 >= 12:00**：第一天补贴 90 元（半天）
- **首程出发时间 < 12:00**：第一天补贴 180 元（全天）
- **末程返回时间 > 12:00**：最后一天补贴 180 元（全天）
- **末程返回时间 <= 12:00**：最后一天补贴 90 元（半天）
- **中间日期**：每天 180 元

### 退票费

火车票退票金额会单独填写在"其他费用"行（第 25 行），摘要写"退票费"，不会与正常车票混淆。

## 打印顺序规则

1. **交通费**（按时间从早到晚）
   - 火车票/飞机票
   - 打车行程单
2. **住宿费**（按时间排序）
   - 酒店结账单
3. **附件**（未被识别为发票的 PDF，如滴滴电子发票、住宿电子发票）
4. **报销单 Excel**（最后打印）

## 配置修改

编辑 `print_reimbursement.py` 修改默认配置：

```python
DEFAULT_FOLDER = r"C:\Users\17625\Desktop\新建文件夹"  # 默认工作目录
PRINTER_NAME = "NPI9D671C (HP LaserJet Pro MFP M226dw)"  # 打印机名称
OLLAMA_URL = "http://localhost:11434/api/generate"       # Ollama 地址
OLLAMA_VISION_MODEL = "glm-ocr:bf16"                     # OCR 模型
SUBSIDY_HALF_DAY = 90   # 半天补贴
SUBSIDY_FULL_DAY = 180  # 全天补贴
```

## 常见问题

### Q: 打印机没有反应？
A: 请检查：
- 打印机是否开机
- 是否有纸张
- 打印机面板是否有错误提示
- 是否连接到同一网络

### Q: WPS 弹出 PDF 导出窗口？
A: 点击"取消"按钮，打印任务会自动发送到 HP 物理打印机

### Q: 发票日期识别错误？
A: skill 会尝试从发票内容提取日期，如失败会按文件顺序打印

### Q: 补贴金额不对？
A: 系统已按首末程交通工具的实际时间自动计算。可在脚本中修改 `SUBSIDY_HALF_DAY` 和 `SUBSIDY_FULL_DAY` 常量

### Q: 住宿费没有填写在最后一天？
A: 这是公司规定，skill 会自动将住宿费填写在出差的最后一天

### Q: 滴滴电子发票或住宿电子发票没有打印？
A: v2.0 已修复此问题。skill 现在会打印文件夹中所有 PDF 附件，确保发票和单据齐全

## 依赖环境

- Python 3.11+
- pdfplumber（PDF 读取）

首次运行请执行 `uv sync` 安装依赖。
