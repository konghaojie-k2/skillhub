## 设计背景

### 问题场景

PHM（设备健康预测）的核心流程：

```
传感器数据 → 工况切分 → 目标量-因子量分析 → 基准模型训练 → 健康度量化
```

**关键问题**：如何评估基准模型的预测质量？

传统方法只看 R²，但 R² 高不代表模型好：
- R² = 0.98 但残差有严重异方差 → 健康打分不可靠
- R² = 0.90 但残差有自相关 → 预测不稳定

### 设计目标

指标应该能：
1. **自动驱动优化** — 不需要手动分析残差图
2. **多维度诊断** — 捕捉异方差、自相关、非正态等问题
3. **PHM 场景适用** — 考虑时序数据和健康度量化需求

---

## 指标公式

```
health_score = R² - α×异方差惩罚 - β×自相关惩罚 - γ×正态性惩罚
```

**默认权重**：α = 0.5, β = 0.3, γ = 0.2

### 权重设计原则

| 维度 | 权重 | 原因 |
|------|------|------|
| 异方差 | 0.5（最高）| 直接影响健康打分的可靠性 |
| 自相关 | 0.3 | 时序预测的稳定性 |
| 正态性 | 0.2 | 辅助指标，影响置信区间 |

## 各维度详解

### 1. 异方差惩罚（Heteroscedasticity Penalty）

**定义**：残差方差随预测值变化的程度

**计算方法**：
```python
heteroscedasticity_penalty = |corr(y_pred, residuals²)|
```

**物理意义**：
- 理想情况：残差方差恒定（同方差）
- 异方差：高预测值区间残差方差大，或低预测值区间方差大

**PHM 场景影响**：
- 健康打分依赖残差大小
- 异方差 → 不同工况下健康打分标准不一致
- 例如：高氧区间残差方差大，健康打分不可靠

**诊断**：
- 惩罚 > 0.3：有异方差问题
- 惩罚 > 0.5：严重异方差

### 2. 自相关惩罚（Autocorrelation Penalty）

**定义**：残差的时序相关性

**计算方法**：
```python
autocorr_penalty = |corr(residuals[:-1], residuals[1:])|
```

**物理意义**：
- 理想情况：残差独立，无时序模式
- 自相关：连续的预测偏差，模型未捕捉时序规律

**PHM 场景影响**：
- 设备数据是时序数据
- 自相关 → 模型未充分利用历史信息
- 可能存在工况切换未建模

**诊断**：
- 惩罚 > 0.3：有自相关问题
- 建议：加入滞后特征、时序模型

### 3. 正态性惩罚（Normality Penalty）

**定义**：残差偏离正态分布的程度

**计算方法**：
```python
skewness = E[(r - μ)³] / σ³
kurtosis = E[(r - μ)⁴] / σ⁴ - 3
normality_penalty = min(1, |skewness|/3) × min(1, |kurtosis|/5)
```

**物理意义**：
- 理想情况：残差服从 N(0, σ²)
- 非正态：存在双峰、厚尾、偏斜

**PHM 场景影响**：
- 正态分布 → 置信区间有意义
- 非正态 → 异常值多，健康打分不稳定
- 双峰分布 → 可能存在多个工况

**诊断**：
- 偏度大：系统性高估/低估
- 峰度大：存在极端残差
- 双峰：数据包含多个模式

## 与经典回归假设的关系

本指标来源于经典线性回归的 Gauss-Markov 假设：

| 经典假设 | 对应惩罚 | 在 PHM 中的意义 |
|----------|---------|----------------|
| 同方差性 | 异方差惩罚 | 健康打分的一致性 |
| 无自相关 | 自相关惩罚 | 时序预测的稳定性 |
| 残差正态 | 正态性惩罚 | 置信区间的有效性 |

### 为什么不只用于线性回归？

虽然假设来自线性回归，但这些诊断指标对所有回归模型都有意义：

| 模型类型 | 适用性 | 说明 |
|---------|--------|------|
| 线性回归 | ⭐⭐⭐ | 假设的来源，完美适用 |
| XGBoost | ⭐⭐ | 不要求这些假设，但指标能诊断预测质量 |
| 神经网络 | ⭐⭐ | 同上，有助于诊断过拟合和泛化 |
| 分位数回归 | ⭐ | 目标不同，指标意义有限 |

## 为什么 PHM 需要这些指标

### 1. 健康度量化依赖残差分布

PHM 的健康打分公式通常为：
```
health_score = f(残差)
```

如果残差分布不好：
- 异方差 → 不同工况下标准不一致
- 自相关 → 健康打分连续偏高/偏低
- 非正态 → 极端健康打分多

### 2. 设备数据是时序数据

- 传感器数据天然有时序性
- 自相关惩罚能捕捉时序模式
- 帮助发现工况切换问题

### 3. 需要可靠的基准模型

基准模型用于：
- 健康打分的参照
- 异常检测
- 预测性维护

模型质量直接决定下游应用效果。

## 适用模型

### ✅ 推荐使用

| 场景 | 原因 |
|------|------|
| PHM 设备健康预测 | 本指标的设计目标 |
| 时序数据回归 | 自相关惩罚有意义 |
| 需要不确定性估计 | 残差分布影响置信区间 |
| 基准模型建立 | y=f(x) 定量关系建模 |

### ⚠️ 谨慎使用

| 场景 | 建议 |
|------|------|
| 纯预测任务 | 如果只关心准确性，R² 即可 |
| 非时序数据 | 自相关惩罚意义有限 |
| 分类问题 | 不适用 |
