# PHM 健康度评估

用于评估设备健康预测（PHM）基准模型的预测质量。

## 核心指标

```
health_score = R² - 0.5×异方差惩罚 - 0.3×自相关惩罚 - 0.2×正态性惩罚
```

| 维度 | 含义 | 理想值 |
|------|------|--------|
| R² | 拟合优度 | 接近 1 |
| 异方差惩罚 | 残差方差随预测值变化的程度 | 0 |
| 自相关惩罚 | 残差的时序相关性 | 0 |
| 正态性惩罚 | 残差偏离正态分布的程度 | 0 |

## 快速使用

```python
from scripts.evaluate_health import evaluate_health

# y_true: 实际值, y_pred: 预测值
metrics = evaluate_health(y_true, y_pred)

print(f"health_score: {metrics['health_score']:.4f}")
print(f"R²: {metrics['r2']:.4f}")
print(f"异方差惩罚: {metrics['heteroscedasticity_penalty']:.4f}")
print(f"自相关惩罚: {metrics['autocorr_penalty']:.4f}")
```

## 适用场景

### ✅ 推荐使用

- **PHM 设备健康预测**：需要用残差做健康打分
- **基准模型建立**：y=f(x) 定量关系建模
- **时序数据回归**：设备传感器数据
- **需要不确定性估计**：残差分布影响决策

### ⚠️ 谨慎使用

- **纯预测任务**：如果只关心准确性，R² 即可
- **分类问题**：不适用
- **非时序数据**：自相关惩罚意义有限

## 诊断指南

### 异方差惩罚高（> 0.3）

**表现**：残差方差随预测值变化（漏斗形）

**原因**：
- 数据存在多个工况
- 不同区间的样本量差异大
- 模型对某些区间拟合不足

**建议**：
- 分工况建模
- 加权回归
- 特征增强

### 自相关惩罚高（> 0.3）

**表现**：残差存在时序模式

**原因**：
- 缺少滞后特征
- 工况切换未建模
- 时间相关因素未捕捉

**建议**：
- 加入滞后特征
- 时序模型（ARIMA、LSTM）
- 分段建模

### 正态性惩罚高（> 0.5）

**表现**：残差分布偏离正态（双峰、厚尾）

**原因**：
- 数据存在多个工况
- 异常值影响
- 模型系统性偏差

**建议**：
- 异常值处理
- 分工况分析
- 模型调参

## 与经典回归假设的关系

本指标来源于经典线性回归的 Gauss-Markov 假设：

| 假设 | 对应惩罚 | PHM 场景意义 |
|------|---------|-------------|
| 同方差 | 异方差惩罚 | 健康打分的可靠性 |
| 无自相关 | 自相关惩罚 | 时序预测的稳定性 |
| 残差正态 | 正态性惩罚 | 置信区间的有效性 |

**为什么 PHM 需要这些**：
- 健康度量化依赖残差分布
- 残差分布不好 → 健康打分不可靠
- 设备数据是时序 → 自相关很重要
